# ターミナル選択範囲の即時翻訳ツール (Tmux Plugin / Script) 実装要件

## 1. 概要
Tmuxのコピーモード（viバインド）で選択したターミナル上のテキスト（エラーログ、ドキュメントなど）を、指定したバックエンド（Google翻訳など）を用いて翻訳し、ポップアップ表示するツールを実装する。

## 2. 機能要件 (UXフロー)
1. **トリガー:** ユーザーがTmuxのコピーモードに入り（`Prefix + [`）、`v` 等でテキストをビジュアル選択する。
2. **実行:** 選択状態で特定のキー（例: `T`）を押下する。
3. **キャプチャ:** 選択されたテキスト領域が取得され、コピーモードが終了する。
4. **翻訳処理:** バックグラウンドで翻訳API/エンジン（Google翻訳等）にキャプチャしたテキストを送信する。
5. **表示:** Tmuxのフローティングウィンドウ（`tmux popup`）が画面中央に展開され、「原文」と「翻訳結果」が表示される。
6. **閲覧と復帰:** ポップアップ内はページャー（`less`など）でスクロール可能。`q` を押すとポップアップが閉じ、元の作業に復帰する。

## 3. 設定要件 (Config)
外部設定ファイル（例: `~/.config/tmux-translate/config`）またはスクリプト内の環境変数の読み込みにより、以下の項目を変更可能にすること。
* **BACKEND:** 翻訳に利用するバックエンドの指定（例: `google`, `deepl` など）。ローカルLLMは対象外。
* **SOURCE_LANG:** 変換元の言語コード（デフォルト: `en` / 英語）。
* **TARGET_LANG:** 変換先の言語コード（デフォルト: `ja` / 日本語）。
* **API_KEY:** 外部APIを利用する場合の認証キー（利用するバックエンドに応じる）。

## 4. 非機能要件
* **依存関係:** 外部バックエンドへのアクセスには `curl`, `jq` や、Google翻訳を利用できるCLIツール（例: `translate-shell`）などを想定する。
* **エラーハンドリング:** ネットワークエラーやAPIの制限超過が発生した場合、ポップアップ内で直感的に原因がわかるエラーメッセージを表示すること。
* **ターミナル環境の維持:** ポップアップ表示によって、背面の作業中のペインやバッファのテキストが破壊・上書きされないこと。

## 5. システムアーキテクチャ・構成要素
### A. Tmux設定 (`tmux.conf`)
* `mode-keys vi` を前提とする。
* `copy-pipe-and-cancel` コマンド等を使用し、選択範囲のテキストをシェルスクリプトにパイプで渡すキーバインドを定義する。
* スクリプトの実行結果を `tmux popup` コマンドでオーバーレイ表示するルーチンを記述する。

### B. 中継・翻訳処理シェルスクリプト (`tmux-translate.sh`)
* 標準入力 (stdin) からテキストを受け取る。
* 設定ファイルから `BACKEND`, `SOURCE_LANG`, `TARGET_LANG` を読み込み、対象の翻訳サービスにリクエストを投げる。
* 翻訳結果と原文を見やすくフォーマット（ANSIエスケープシーケンスでの色付けなど）し、標準出力に返す。

## 6. コーディングエージェントへの実装指示事項
上記要件を満たすために、以下のコード成果物を作成してください。

1. **`~/.tmux.conf` への追加スニペット:** * 選択範囲を一時ファイルまたはパイプ経由でスクリプトへ渡し、`tmux popup` を起動する設定。
2. **設定ファイルのサンプル (`config`):** * 変換元・変換先の言語、およびバックエンド（Google等）を指定するテンプレート。
3. **`tmux-translate.sh` の完全なスクリプト:**
   * 設定ファイルの読み込みと、言語指定（デフォルト: en -> ja）の適用。
   * Google翻訳（または指定バックエンド）のAPI/CLI呼び出し処理。
   * `less -R` を用いて、色付きのままポップアップ内で `j`/`k` スクロール可能にする出力処理。
4. **`README.md` の作成（インストール手順の詳細化）:**
   * ツールの概要と使い方。
   * 動作に必要な依存ツール（`translate-shell`, `curl`, `jq` など）のインストールコマンド（macOS/Linux向け）。
   * スクリプトの配置（`~/.local/bin/` へのパス通しなど）および実行権限の付与手順（`chmod +x`）。
   * 設定ファイル（`~/.config/...`）の配置手順。
   * `~/.tmux.conf` への設定反映と、Tmuxの再読み込み手順（`tmux source ~/.tmux.conf`）。
